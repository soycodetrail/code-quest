## P2-2 GdUnit4 单元测试

### 为什么用 GdUnit4

Godot skill 默认推荐，提供 `assert_int/assert_str/assert_array` 等丰富断言，支持 CI、面试加分项。代价：addon ~3.6MB 进仓库。

### 兼容性坑（重要）

**GdUnit4 v6.1.3 与 Godot 4.7 不兼容**——报 `Class "GdUnitAssertImpl" hides a global script class`。Godot 4.7 收紧了重名 `class_name` 检查，GdUnit4 的 `addons/src/` 和 `addons/gdUnit4/src/` 两份重复代码触发冲突。

**修复**：降级 Godot 4.7 → 4.6.1（多版本共存）。

### 安装

```bash
# 1. 下载 GdUnit4 v6.1.3
git clone --depth 1 --branch v6.1.3 https://github.com/godot-gdunit-labs/gdUnit4.git /tmp/gdunit4-src
cp -R /tmp/gdunit4-src/addons/gdUnit4 <项目>/addons/

# 2. project.godot 启用 plugin
[editor_plugins]
enabled=PackedStringArray("res://addons/gdUnit4/plugin.cfg")

# 3. 跑测试
godot --headless --path . -s res://addons/gdUnit4/bin/GdUnitCmdTool.gd -a tests/ -c --ignoreHeadlessMode
```

⚠️ **注意**：`--ignoreHeadlessMode` 必须加，否则 GdUnit4 拒绝在 headless 下跑。

### 测试写法

```gdscript
class_name TestMiniPython
extends GdUnitTestSuite

var _interp

func before_test() -> void:
    _interp = load("res://scripts/MiniPythonInterpreter.gd").new()

func test_arithmetic() -> void:
    var cases := {
        "print(1 + 2)": "3",
        "print(15 // 4)": "3",
        "print(2 ** 10)": "1024",
    }
    for code in cases:
        var r: Dictionary = _interp.execute(code)
        assert_str(_strip(r.output)).is_equal(cases[code])
```

⚠️ **`var r := _interp.execute(...)` 推断报错**，必须 `var r: Dictionary = ...`。

### GdUnit4 v6 API 改名

`begins_with` → `starts_with`：
```gdscript
# 错：assert_str(r.output).begins_with("前进")
# 对：
assert_str(r.output).starts_with("前进")
```

### AppTheme.gd（Autoload）

`_ready` 构建 Theme，监听 `tree_changed` 信号捕获场景切换自动套用：
```gdscript
func _ready() -> void:
    theme = ThemeBuilder.build()
    call_deferred("_bootstrap")  # 延迟到 SceneTree 就绪

func _apply_theme_to_current_scene() -> void:
    if is_inside_tree() == false: return  # null guard
    var scene := get_tree().current_scene
    if scene is Control:
        (scene as Control).theme = theme
```

### 踩坑

1. **`Color.darker()` 不存在**（4.x 删了 3.x 的 API）：手动算 RGB `Color(r*0.7, g*0.7, b*0.7)`
2. **Autoload `_ready` 时 SceneTree 还没就绪**：用 `call_deferred` + `is_inside_tree()` null guard

## P2-4 扩展 MiniPython + 5 个新关卡

### MiniPython 扩展

加 dict + 方法调用 + in 运算符：

```gdscript
# parse_postfix 加 . 方法调用
elif check("OP", "."):
    advance()
    var method_name: String = advance().value
    # 解析 (args)
    e = {"_t": "method", "obj": e, "method": method_name, "args": args, ...}

# parse_primary 加 {k: v} dict 字面量
if t.value == "{":
    advance()
    var pairs: Array = []
    while not check("OP", "}"):
        var k = parse_expr()
        expect("OP", ":")
        var v = parse_expr()
        pairs.append([k, v])
    return {"_t": "dict", "pairs": pairs, ...}

# parse_comparison 加 in / not in
while ... or check("KEYWORD", "in") or check("KEYWORD", "not"):
    if check("KEYWORD", "not"):
        advance()
        _match("KEYWORD", "in")
        left = {"_t": "binop", "op": "not_in", ...}
```

**词法分析器**也要加 `{` `}` 到运算符白名单：
```gdscript
if ch in "+-*/%=<>()[],:.{}":  # 加 {}
```

### 字符串/列表/字典方法

```gdscript
func _string_method(s, method, args):
    match method:
        "upper":  return s.to_upper()
        "lower":  return s.to_lower()
        "split":  return _to_array(s.split(args[0]))  # 转 Array 避免 typed array
        "replace": return s.replace(args[0], args[1])
        ...

func _dict_method(d, method, args):
    match method:
        "keys":   return _to_array(d.keys())
        "get":    return d.get(args[0], args[1] if args.size() > 1 else null)
        ...
```

## 经验总结

1. **测试要早**：P2-2 才接入 GdUnit4 是晚了，理想是 P1 就接入。每次扩 MiniPython 都靠测试保回归
2. **程序化美术是教学游戏的最优解**：零资源、品牌统一、跨平台一致
3. **`class_name` 全局类要在头一行**：否则其他脚本引用不到
4. **Godot 4.x 删了不少 3.x API**（`Color.darker` / `Color.lighter`），迁移代码要查
5. **新加语法特性必须配套测试**：dict 加完后立刻写 16 个 v2 测试用例，发现 `len(dict)` / `for k in dict` / typed array 三个 bug
