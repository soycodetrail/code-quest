## P0-1 Python 语法高亮

### 实现思路

Godot 的 `CodeEdit` 节点支持 `syntax_highlighter` 属性，赋一个继承 `CodeHighlighter` 的对象即可。重写 `_get_line_syntax_highlighting(line: int)` 方法返回 `Dictionary[int, {color: Color}]`。

**关键坑**：`_get_line_syntax_highlighting` 的参数是**行号**（int），不是行文本。需要自己持有 CodeEdit 引用来取文本。详见 [[07-GDScript 语言陷阱汇总]]。

### PythonSyntaxHighlighter.gd

```gdscript
class_name PythonSyntaxHighlighter
extends CodeHighlighter

const COLOR_KEYWORD := Color(0.53, 0.67, 1.0)    # 蓝 - 关键字
const COLOR_STRING := Color(0.6, 0.9, 0.5)        # 绿 - 字符串
const COLOR_COMMENT := Color(0.45, 0.45, 0.5)     # 灰 - 注释
const COLOR_NUMBER := Color(0.95, 0.7, 0.3)       # 橙 - 数字
const COLOR_BUILTIN := Color(0.7, 0.5, 0.9)       # 紫 - 内置函数

const PYTHON_KEYWORDS := {"if": true, "else": true, "for": true, ...}
const PYTHON_BUILTINS := {"print": true, "range": true, "len": true, ...}

var _code_edit: CodeEdit = null

func set_code_edit(edit: CodeEdit) -> void:
    _code_edit = edit

func _get_line_syntax_highlighting(line: int) -> Dictionary:
    var color_map := {}
    if _code_edit == null: return color_map
    var line_text := _code_edit.get_line(line)
    # 词法扫描 line_text，按关键字/字符串/注释/数字/标识符着色
    ...
    return color_map
```

### 弹跳动画（Tween）

```gdscript
func _bounce_character() -> void:
    if character_animating: return
    character_animating = true
    var orig_pos = character_sprite.position
    var tween = create_tween()
    tween.set_parallel(false)
    tween.tween_property(character_sprite, "position:y", orig_pos.y - 30, 0.2).set_trans(Tween.TRANS_SINE)
    tween.tween_property(character_sprite, "position:y", orig_pos.y, 0.2).set_trans(Tween.TRANS_BOUNCE)
    tween.tween_callback(func(): character_animating = false)
```

### 抖动动画（Tween 循环）

```gdscript
func _shake_character() -> void:
    var orig_pos = character_sprite.position

        tween.tween_property(character_sprite, "position:x", orig_pos.x - 8, 0.05)
    tween.tween_property(character_sprite, "position:x", orig_pos.x, 0.05)
```

## P0-4 通关庆祝动画

### 庆祝粒子（程序化生成）

20 颗 Unicode 符号粒子（`★✦◆●▲`）向上飞：
```gdscript
func _spawn_celebration() -> void:
    var colors = [Color.RED, Color.GREEN, Color.BLUE, Color.YELLOW, Color.ORANGE, Color.VIOLET]
    for i in 20:
        var particle = Label.new()
        particle.text = ["★", "✦", "◆", "●", "▲"][i % 5]
        particle.modulate = colors[i % colors.size()]
        particle.position = Vector2(center_x + randf_range(-60, 60), center_y)
        character_area.add_child(particle)
        var tween = create_tween()
        tween.set_parallel(true)
        var angle = randf_range(-PI, 0)  # 向上飞
        var distance = randf_range(60, 120)
        tween.tween_property(particle, "position:x", particle.position.x + cos(angle) * distance, 0.8)
        tween.tween_property(particle, "position:y", particle.position.y + sin(angle) * distance, 0.8)
        tween.chain().tween_property(particle, "modulate:a", 0.0, 0.4)
        tween.chain().tween_callback(particle.queue_free)
```

## 踩坑与修复

### 坑 1：PythonRunner 用了不存在的 ProcessNode 类型

```gdscript
# 错：
var _process: ProcessNode = null
# 对：直接删掉这行（未使用）
```

### 坑 2：OS.get_cache_path() 静态调用失败

```gdscript
# 错：OS.get_cache_path()（GDScriptNativeClass 上找不到静态方法）
# 对：用 user:// 目录 + globalize_path 转绝对路径
var tmp_path = "user://code_quest_player.py"
var abs_path = ProjectSettings.globalize_path(tmp_path)
OS.execute("python3", [abs_path], output, true)
```

### 坑 3：场景节点路径与脚本 @onready 不匹配

场景用 `MainSplit/LeftPanel/...` 嵌套结构，但脚本写 `$LeftPanel/...`。所有 @onready 路径改成完整的 `$MainSplit/LeftPanel/...`。

### 坑 4：场景缺节点导致运行时崩溃

脚本 @onready 引用的节点（ProgressBar / CharacterSprite / EffectLabel / CelebrationOverlay）场景里没有。**在 .tscn 里手动加这些节点**。

## 经验总结

1. **CodeHighlighter 的 `_get_line_syntax_highlighting(line: int)` 参数是行号不是文本**，必须持有 CodeEdit 引用
2. **Tween 动画用 `set_parallel(false)` + `set_trans(Tween.TRANS_BOUNCE)` 做弹跳效果**，比手动 lerp 简单
3. **场景节点路径必须和脚本 @onready 完全对应**，否则运行时 null 崩溃
4. **场景改完要跑 `--quit-after 2` 验证 _ready 不崩**，光编译过不够
