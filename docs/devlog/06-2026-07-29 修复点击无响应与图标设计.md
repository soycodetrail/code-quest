## Bug：游戏点击无响应

### 现象

APK 装到模拟器，启动后 MainMenu 渲染正常，但点击"开始闯关"按钮无反应。

### 排查过程

#### 第一步：怀疑 UI 节点被遮挡

先检查 MainMenu 场景的节点层级，担心 CelebrationOverlay 或 Background 拦截点击。但 MainMenu 根本没有 CelebrationOverlay。VBox 容器尺寸确实偏小（240×160，容不下 4 个 50 高按钮），修大了，但问题没解决。

#### 第二步：查 logcat 找真因

```bash
adb logcat -d | grep -iE "godot |error"
```

看到关键错误：
```
E godot : ERROR: QueuePresentKHR failed with error: 5
W InputDispatcher: Not sending touch gesture to ... top.soycodetrail.codequest because it has config NO_INPUT_CHANNEL
```

**两个关键信号**：
1. `QueuePresentKHR failed with error: 5` —— Vulkan 渲染失败
2. `NO_INPUT_CHANNEL` —— 触摸事件根本没传给 Activity

### 根因

`project.godot` 用 `renderer/rendering_method="mobile"`（Vulkan Forward Mobile），在 Android 模拟器（软件 GPU llvmpipe）上渲染崩溃（`VK_ERROR_OUT_OF_DATE_KHR`）。渲染崩溃导致 Activity 没有 input channel，触摸事件被系统丢弃。

**这不是 UI 问题，是渲染问题。**

### 修复

渲染器改 `gl_compatibility`（OpenGL ES 3.0）：

```ini
[rendering]
renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
textures/vram_compression/import_etc2_astc=true
```

`gl_compatibility` 兼容性最好：
- Android 真机/模拟器/老设备全稳
- 不依赖 Vulkan 驱动
- 性能稍差但教学游戏够用

### 验证

```bash
# 重新 build + install + launch
adb install -r build/CodeQuest-debug.apk
adb shell am start -n top.soycodetrail.codequest/com.godot.game.GodotAppLauncher

# 看渲染日志
adb logcat -d | grep -iE "GLES|OpenGL|godot"
# 看到：I godot : OpenGL API OpenGL ES 3.0 (4.1 Metal ...) - Compatibility
# 没有 QueuePresentKHR 错误

# ADB 模拟点击"开始闯关"按钮
adb shell input tap 960 420
sleep 3
adb shell dumpsys window | grep mCurrentFocus
# 应该从 MainMenu 切到 GameScene
```

截图确认：点击后成功进入"第一章 森林入门 / 第 1 关：第一步 / 知识点：print()"。

### 经验

> **Godot Android 点击无响应，先查渲染器**。
> 如果 logcat 看到 `QueuePresentKHR failed` 或 `NO_INPUT_CHANNEL`，根因是渲染崩溃导致 Activity 没拿到 input 通道，不是 UI 的问题。直接 `gl_compatibility` 解决。

## 法师主题游戏图标

### 设计概念

业界最优 + 主题统一：
- **主体**：法师立绘（与 `ThemeBuilder.make_character_sprite` 一致，品牌统一）
- 圆头 + 三角帽 + 帽尖星星 + 法杖
- **法球上放 `</>` 代码符号**（点明 Python 编程主题）
- 配色：深紫蓝径向渐变背景 + 蓝紫主色 + 金色法球（与游戏 COLOR_* 一致）
- flat design 风格，圆角，无描边

### SVG 源（icon.svg）

256×256 矢量，关键元素：
- `<radialGradient id="bg">`：深紫蓝径向渐变（#3A4FBF → #0F1438）
- 背景星点装饰（小白圆 + opacity）
- 长袍梯形（深蓝）+ 3 颗金色扣子
- 圆头（肤色）+ 脸颊微红 + 黑色眼睛 + 微笑
- 三角帽（蓝紫渐变）+ 帽尖星星（金色）
- 法杖（棕色斜线）+ 法球（金橙径向渐变）
- 法球上的 `</>` 代码符号（黑色 path + line）

### 生成各尺寸 PNG

SVG 不能直接当 Android launcher icon，用 sharp（Node.js）渲染各尺寸：

```bash
cd /tmp && npm install sharp
cat > render.js << 'EOF'
const sharp = require('sharp');
const fs = require('fs');
const svg = fs.readFileSync('/path/to/icon.svg');
const sizes = [
  { name: 'icon-512.png', size: 512 },
  { name: 'icon-192.png', size: 192 },
  { name: 'icon-48.png', size: 48 },
];
(async () => {
  for (const s of sizes) {
    await sharp(svg, { density: 384 }).resize(s.size, s.size).png().toFile('/tmp/' + s.name);
  }
})();
EOF
node render.js
```

⚠️ **不要用 cairosvg**（macOS 缺 libcairo 系统库，安装复杂）。sharp 自带原生绑定，零依赖。

### Android 图标配置

`export_presets.cfg`：
```ini
launcher_icons/main_192x192="res://icon-192.png"
launcher_icons/adaptive_foreground_432x432="res://icon-512.png"
launcher_icons/adaptive_background_432x432="res://icon-512.png"
```

### 验证

APK 打包后 `aapt dump badging` 看到：
```
application: label='Code Quest' icon='res/mipmap-anydpi-v26/icon.xml'
```

模拟器 launcher 截图：法师图标清晰可辨，专业感强。

## 经验总结

1. **Android 点击无响应先查 logcat**，关键词：`QueuePresentKHR` / `NO_INPUT_CHANNEL`
2. **`gl_compatibility` 是 Godot Android 的最稳渲染器**，模拟器和老设备都兼容
3. **macOS 渲染 SVG 用 sharp**（npm），不要用 cairosvg（缺系统库）
4. **launcher icon 要配 adaptive foreground/background**，否则部分 launcher 显示异常
5. **图标设计要品牌统一**——这里图标法师和游戏内 ThemeBuilder 法师是同一个 IP
