# 🎮 Code Quest - Python 编程闯关游戏

> 在游戏中学 Python——写代码控制角色闯关，从基础语法到算法实战。

## 游戏概念

玩家扮演一个冒险者，在奇幻世界中通过编写 Python 代码来解决谜题、击败怪物、收集宝藏。

### 关卡设计（渐进式）

| 章节 | 主题 | 编程知识点 | 游戏玩法 |
|------|------|-----------|---------|
| 第 1 章 | 森林入门 | print、变量、input | 写代码控制角色走到终点 |
| 第 2 章 | 迷宫探险 | if/else、for 循环 | 条件判断选择路径 |
| 第 3 章 | 宝藏猎人 | while、列表 | 循环收集金币 |
| 第 4 章 | 怪物战斗 | 函数定义 | 封装战斗策略 |
| 第 5 章 | 城堡谜题 | 字典、文件读写 | 数据管理解谜 |
| 第 6 章 | 龙之挑战 | 算法（排序/搜索）| 综合应用 |

### 技术栈

- **引擎**：Godot 4.x（开源免费，支持 Android/Windows/macOS）
- **编程语言**：GDScript（游戏逻辑）+ Python（玩家输入）
- **Python 集成**：通过 GDScript 调用 Python 解释器，或用 JavaScript（代码沙箱）
- **美术**：像素风（免费素材）

## 平台

- Android（手机/平板）
- Windows（桌面）
